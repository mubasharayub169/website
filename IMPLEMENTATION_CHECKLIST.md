## 🔧 CSS Modification Guide

### To adjust button glow:
```css
.btn-login {
    box-shadow: var(--shadow-neon);  /* Modify this line */
}
```

### To change animation speed:
```css
.btn-login:hover {
    animation: glow 2s ease-in-out infinite;  /* Change "2s" to desired time */
}
```

### To adjust hover scale:
```css
.link-card:hover {
    transform: translateY(-18px) scale(1.03);  /* Change "1.03" to desired scale */
}
```
